# Security Tools

Small Python tools I build while learning offensive security. Each tool lives in its own folder with a README explaining what it does, how to run it, and what I learned.

**For authorized use only.** Run these only against systems you own or have written permission to test.

## Tools

| Tool | What it does | Status |
|---|---|---|
| [portscan](portscan/README.md) | TCP connect scan of a target host (ports 1 to 1024) | Done |
| Banner grabber | Connects to open ports and reads service banners | Planned |

*Tools are added as I learn the concepts behind them.*
